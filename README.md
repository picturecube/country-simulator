# Country Simulator
(i didn't have a creative name for this)

**This is a political simulator built with Node.js and p5.js showing how land and politics affects the world**

## How to use
1. Make sure you have installed Node.js if you haven't already.
2. Go to your terminal.
3. Make sure you enter the directory this is installed in (should be `C:/your/path/country-simulator` or `~/your/path/country-simulator`).
4. Run `npm install` if running for the first time.
5. Run `npx vite` to start the local server or run `npx vite -w` if you want to edit and see the result in real time.
6. Go to `localhost:5173` (or whatever the terminal output specified) or click the link if your terminal allows it.
7. You should be good to go!
