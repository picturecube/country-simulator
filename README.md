# Country Simulator
(i didn't have a creative name for this)

**This is a political simulator showing how land and politics affects the world**

## How to use
1. Go to your terminal.
2. Make sure you enter the directory this is installed in (should be `C:/your/path/country-simulator` or `~/your/path/country-simulator`).
3. Run `npm install` if running for the first time.
4. Run `npx vite` to start the local server.
5. Go to `localhost:5173` (or whatever the terminal output specified) or click the link if your terminal allows it.
6. You should be good to go!
